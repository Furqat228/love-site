# Романтический сайт ❤️

## Важно
- Камера включается только после нажатия кнопки.
- Фото показывается для проверки и отправляется только после отдельного нажатия «Да, отправить фото» и подтверждения.
- Токен Telegram хранится только в переменных окружения сервера. Никогда не помещай токен в `public/index.html` или публичный репозиторий.
- Для камеры нужен HTTPS (платформы хостинга обычно предоставляют его автоматически).

## 1. Создать Telegram-бота
1. В Telegram открой `@BotFather`.
2. Отправь `/newbot`, придумай имя и username бота.
3. Скопируй выданный токен. Не публикуй его и никому не отправляй.
4. Открой своего нового бота и нажми Start.
5. Чтобы получить свой chat ID: отправь боту любое сообщение, затем открой в браузере `https://api.telegram.org/botВАШ_ТОКЕН/getUpdates` (подставь токен только у себя). В ответе найди `"chat":{"id":123456789...}` — это твой CHAT_ID. После получения результата не делись ссылкой, потому что она содержит секретный токен.
6. Не публикуй токен. Если он случайно стал доступен другим, отзови его через @BotFather командой `/revoke` и создай новый.

## 2. Разместить на Render через телефон
1. Создай аккаунт на GitHub и новый репозиторий, например `romantic-photo-site`.
2. Загрузи в корень репозитория папки и файлы из этого проекта: `public/`, `server.js`, `package.json`, `README_RU.md`.
3. На Render создай новый **Web Service** и подключи GitHub-репозиторий.
4. Build Command: `npm install`
5. Start Command: `npm start`
6. В разделе Environment добавь:
   - `BOT_TOKEN` = токен от BotFather
   - `CHAT_ID` = твой Telegram chat ID
7. Нажми Deploy. Render выдаст HTTPS-ссылку. Открой её на телефоне и проверь.

У бесплатных тарифов хостинга могут быть ограничения/паузы; доступность тарифов меняется. Не загружай секретный токен в файлы репозитория.

## 3. Проверка
- Открой сайт по HTTPS.
- Нажми «Сделать фото», разреши камеру, сделай снимок.
- Проверь превью. Нажми «Не отправлять» — фото не уйдёт.
- Для тестовой отправки нажми «Да, отправить фото» и подтверди.
- Сервер отправляет только JPEG до 8 МБ.

## Примечания
Это стартовый проект без базы данных. Фотографии не сохраняются на сервере намеренно: изображение находится в памяти во время обработки и отправляется боту. Для реального публичного использования стоит добавить ограничение частоты запросов и защиту от спама.
